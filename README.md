# 🍨 The Ice Cup

A modern, responsive frontend web application for a fictional ice cream parlour built using **React.js**, **Vite**, and **Tailwind CSS**.

The project features a visually appealing user interface, responsive layouts, menu browsing, shopping cart functionality, authentication pages, and customer-focused sections.

## 🚀 Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/muqtadirkhxn/the-ice-cup.git
```

### 2️⃣ Navigate to Project

```bash
cd the-ice-cup
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Run Development Server

```bash
npm run dev
```

### 5️⃣ Build for Production

```bash
npm run build
```

### 6️⃣ Preview Production Build

```bash
npm run preview
```
